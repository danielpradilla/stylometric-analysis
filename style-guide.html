Style Direction

The tool should feel like a working analysis bench: dense enough for repeated use, calm enough for interpretation, and explicit about uncertainty.

Avoid decorative hero sections. The first viewport is the tool itself.

Type And Controls

  • --font-xs 11px for labels and table headers.
  • --font-sm 13px for dense metrics.
  • --font-md 15px for default UI text.
  • --font-lg 20px for panel headings.
  • --font-xl 32px for page title only.
  • --radius 8px for cards and controls.
