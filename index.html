    User Guide

    1. Compare two samples

    Paste text into Text A and Text B, or upload plain text files. Use at least 500 words per sample when possible. The tool can run on shorter passages, but confidence drops quickly.

    2. Read the evidence

    The score combines function words, character n-grams, word-length curves, punctuation, sentence rhythm, and lexical richness. Review the charts and differences before trusting the verdict.

    3. Check AI-style mismatch

    Add known writing in the reference box. The audit compares Text B against the person's normal variation. It can flag an atypical passage, but it cannot prove that a passage was AI-written.

    4. Tune the run

    Strict sensitivity raises the same-author threshold. More frequent words and 3-gram character patterns usually work well for English prose. Ignore quoted blocks when emails or essays contain long citations.
